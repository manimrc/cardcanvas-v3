# Sleekly Card UX & Whiteboard Collision Improvements Record

This file documents the full implementation of the Phase 1 card readability, outline navigation, zoom/pan controls, and resize collision prevention. Use this guide to easily migrate these features to the **3-Tier modular monolith** and **Microservices** versions of Sleekly.

---

## 🛠️ Summary of Implemented Features

1. **Widescreen Modal Canvas**: Modal width expanded to `1240px` (with `880px` text column) for a premium document editing feel.
2. **Centered Viewport & Sticky Controls**: Centered the expanded modal vertically. The modal height is fixed to `calc(100vh - 48px)`, confining scrolling to the document text itself. The header, toolbar, and outline stay docked in place.
3. **Always-Editable click experience**: Card opens immediately in edit mode. Removed the "Edit / Done" toggle. Tags input is borderless with a tag icon.
4. **Dynamic Outline (Table of Contents)**: Reads `h1`, `h2`, `h3` nodes from TipTap in real-time, displaying them in a sticky right sidebar. Clicking an outline item moves the text selection to the heading, focuses the editor, and scrolls smoothly to it.
5. **Expanded Image Zoom & Pan**: Adds floating controls (`+`, `-`, `Reset`) to zoom images up to 4x. Panning is supported via click-and-drag. Double-clicking toggles 1x/2x zoom.
6. **Canvas Resizing Overlap Prevention**: Restricts card resizing in real-time. If expanding causes a collision, it halts expansion in the blocked direction while allowing it in free directions.

### Step 2: Component State & Outline Logic
Add these states and callbacks inside `RichTextEditor`:

```typescript
  // Set always editable by default
  const [isEditing, setIsEditing] = useState(true);
  const [headings, setHeadings] = useState<{ id: string; text: string; level: number; pos: number }[]>([]);

  // Image Zoom & Pan States
  const [zoomScale, setZoomScale] = useState(1);
  const [panOffset, setPanOffset] = useState({ x: 0, y: 0 });
  const [isDragging, setIsDragging] = useState(false);
  const dragStart = useRef({ x: 0, y: 0 });

  // Update Outline on TipTap updates
  useEffect(() => {
    if (!editor) return;

    const updateHeadings = () => {
      const list: typeof headings = [];
      editor.state.doc.descendants((node: any, pos: number) => {
        if (node.type.name === 'heading') {
          list.push({
            id: `heading-${pos}`,
            text: node.textContent || 'Untitled Section',
            level: node.attrs.level,
            pos,
          });
        }
      });
      setHeadings(list);
    };

    updateHeadings();

    editor.on('update', updateHeadings);
    return () => {
      editor.off('update', updateHeadings);
    };
  }, [editor]);

  // Navigate to Heading - selection-focus fix to prevent scroll-jumps
  const scrollToHeading = useCallback((pos: number) => {
    if (!editor) return;
    editor.commands.setTextSelection(pos);
    editor.commands.focus();
    const domNode = editor.view.nodeDOM(pos);
    if (domNode instanceof HTMLElement) {
      domNode.scrollIntoView({ behavior: 'smooth', block: 'start' });
    }
  }, [editor]);

  // Drag-to-Pan Handlers
  const handleImageMouseDown = useCallback((e: React.MouseEvent) => {
    if (zoomScale <= 1) return;
    e.preventDefault();
    setIsDragging(true);
    dragStart.current = { x: e.clientX - panOffset.x, y: e.clientY - panOffset.y };
  }, [zoomScale, panOffset]);

  const handleImageMouseMove = useCallback((e: React.MouseEvent) => {
    if (!isDragging) return;
    const nextX = e.clientX - dragStart.current.x;
    const nextY = e.clientY - dragStart.current.y;
    setPanOffset({ x: nextX, y: nextY });
  }, [isDragging]);

  const handleImageMouseUp = useCallback(() => {
    setIsDragging(false);
  }, []);

  const handleZoomIn = useCallback(() => {
    setZoomScale(prev => Math.min(prev + 0.25, 4));
  }, []);

  const handleZoomOut = useCallback(() => {
    setZoomScale(prev => {
      const next = Math.max(prev - 0.25, 1);
      if (next === 1) {
        setPanOffset({ x: 0, y: 0 });
      }
      return next;
    });
  }, []);

  const handleZoomReset = useCallback(() => {
    setZoomScale(1);
    setPanOffset({ x: 0, y: 0 });
  }, []);

  const handleImageDoubleClick = useCallback(() => {
    if (zoomScale > 1) {
      handleZoomReset();
    } else {
      setZoomScale(2);
    }
  }, [zoomScale, handleZoomReset]);
```

## 🎨 3. Canvas Resizing Overlap Prevention (`InfiniteCanvas.tsx`)

Apply these updates in `src/components/Canvas/InfiniteCanvas.tsx` to stop resized cards from overlapping:

### Step 1: Import Collision Helper
Import `hasOverlap` from your collision file alongside `findNonOverlappingPosition`:
```typescript
import { findNonOverlappingPosition, hasOverlap } from '@/lib/collision';
```

### Step 2: Refactor `handleResize`
Update `handleResize` to query overlap before calling updates:

```typescript
  const handleResize = useCallback(
    (id: string, width: number, height: number) => {
      if (readOnly) return;
      const card = cards.find(c => c.id === id);
      if (!card) return;

      const proposedRect = { x: card.x, y: card.y, width, height };

      // If proposed dimensions don't overlap, apply size
      if (!hasOverlap(proposedRect, cards, id)) {
        onUpdateCard({ id, width, height });
      } else {
        // Evaluate horizontal and vertical resizing independently
        const widthOk = !hasOverlap({ x: card.x, y: card.y, width, height: card.height }, cards, id);
        const heightOk = !hasOverlap({ x: card.x, y: card.y, width: card.width, height }, cards, id);

        const finalW = widthOk ? width : card.width;
        const finalH = heightOk ? height : card.height;

        if (finalW !== card.width || finalH !== card.height) {
          onUpdateCard({ id, width: finalW, height: finalH });
        }
      }
    },
    [onUpdateCard, readOnly, cards]
  );
```
